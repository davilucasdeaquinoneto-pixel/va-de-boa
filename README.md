# Vá de Boa — Projeto Turma 41

Campanha educativa independente sobre bicicletas elétricas, desenvolvida pela Turma 41 do curso de Aprendizagem Profissional em Comércio de Bens, Serviços e Turismo.

## Publicação
Projeto preparado para publicação como **Static Site** no Render.

## Estrutura
- `index.html`: site principal.
- `assets/`: CSS, JavaScript, imagens, capas e vídeos.
- `render.yaml`: configuração de publicação, segurança e cache.
- `SECURITY_REVIEW.md`: revisão estática de segurança.
- `404.html`: página de erro.

## Responsividade
A interface foi preparada para desktop, tablets e celulares, incluindo menu responsivo, cards, páginas de regras, vídeos, acessibilidade e rodapé.

## Vídeos
A seção de vídeos contém:
- **Elétrica é tudo igual?** — vídeo da campanha.
- **Vá de Boa: guia rápido do site** — tutorial de navegação.

> Projeto acadêmico independente feito por alunos do curso de Aprendizagem Profissional em Comércio de Bens, Serviços e Turismo. Não é um site oficial do Senac e não representa comunicação institucional da organização.
